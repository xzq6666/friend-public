## 2 环境准备

### 2.1 安装 JDK 17

**Windows:**
```bash
# 下载并安装 JDK 17
# 配置环境变量
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.x.x
set PATH=%JAVA_HOME%\bin;%PATH%

# 验证安装
java -version
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install openjdk-17-jdk

# 验证安装
java -version
```

### 2.2 安装 MySQL 8.0

**Windows:**
```bash
# 下载 MySQL Installer 安装
# 安装过程中设置 root 密码
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全初始化
sudo mysql_secure_installation
```

**创建数据库:**
```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE smart_recruitment DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建专用用户（推荐，可选）
CREATE USER 'recruitment'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON smart_recruitment.* TO 'recruitment'@'localhost';
FLUSH PRIVILEGES;
```

> 系统启动时会自动执行 `schema.sql` 初始化表结构。

### 2.3 安装 Redis

**Windows:**
```bash
# 下载 Windows 版 Redis 或使用 WSL
# 推荐使用 Memurai 或 Redis for Windows
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install redis-server
sudo systemctl start redis
sudo systemctl enable redis

# 验证
redis-cli ping
# 应返回 PONG
```

### 2.4 安装 Maven

**Windows:**
```bash
# 下载 Maven 解压到目录
# 配置环境变量
set MAVEN_HOME=C:\apache-maven-3.x.x
set PATH=%MAVEN_HOME%\bin;%PATH%

# 验证
mvn -version
```

**Linux:**
```bash
sudo apt install maven
mvn -version
```

## 3 应用配置

### 3.1 配置文件

配置文件路径：`src/main/resources/application.yml`

### 3.2 数据库配置

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/smart_recruitment?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: root           # 修改为实际用户名
    password: 123456         # 修改为实际密码
```

### 3.3 Redis 配置

```yaml
spring:
  data:
    redis:
      host: localhost         # Redis 地址
      port: 6379              # Redis 端口
      password:               # Redis 密码（无密码留空）
      database: 4             # 使用的数据库编号
      timeout: 3000ms
```

### 3.4 文件上传配置

```yaml
upload:
  local-path: F:/Java/智能招聘匹配平台/uploads    # 修改为实际存储路径
  max-size: 10MB
```

### 3.5 阿里云 OSS 配置（可选）

```yaml
oss:
  enabled: false                              # 设为 true 启用 OSS
  endpoint: oss-cn-hangzhou.aliyuncs.com      # OSS 端点
  access-key-id: your_access_key_id           # 访问密钥 ID
  access-key-secret: your_access_key_secret   # 访问密钥 Secret
  bucket-name: your-bucket-name               # Bucket 名称
```

### 3.6 AI 服务配置

```yaml
bailian:
  api-key: your_api_key                       # LongCat API 密钥
  model: LongCat-2.0-Preview                  # AI 模型名称
  base-url: https://api.longcat.chat/anthropic # API 地址
  timeout: 30000                              # 超时时间(ms)
```

### 3.7 服务器配置

```yaml
server:
  port: 8081                    # 服务端口
  servlet:
    context-path: /api          # 接口路径前缀
```

### 3.8 JWT 配置

```yaml
jwt:
  secret: your_jwt_secret_key_here_make_it_long_and_secure   # JWT 签名密钥（务必修改）
  expiration: 86400000          # Token 有效期（24小时）
```

### 3.9 环境变量方式配置（推荐用于生产）

为避免敏感信息硬编码在配置文件中，推荐使用环境变量：

```bash
# 设置环境变量
export DB_URL=jdbc:mysql://your-db-host:3306/smart_recruitment
export DB_USERNAME=your_username
export DB_PASSWORD=your_password
export REDIS_HOST=your-redis-host
export REDIS_PASSWORD=your-redis-password
export JWT_SECRET=your_very_long_and_secure_jwt_secret_key
export OSS_ACCESS_KEY_ID=your_oss_key
export OSS_ACCESS_KEY_SECRET=your_oss_secret
export BAILIAN_API_KEY=your_api_key
```

配置文件中使用环境变量引用：
```yaml
spring:
  datasource:
    url: ${DB_URL}
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
```

## 5 部署运行

### 5.1 开发环境运行

```bash
# 方式一：Maven 直接运行
mvn spring-boot:run

# 方式二：运行 JAR 包
java -jar target/smart-recruitment-platform-1.0.0.jar
```

### 5.2 生产环境运行

```bash
# 前台运行
java -jar smart-recruitment-platform-1.0.0.jar

# 后台运行
nohup java -jar smart-recruitment-platform-1.0.0.jar > app.log 2>&1 &

# 指定配置文件运行
java -jar smart-recruitment-platform-1.0.jar --spring.profiles.active=prod

# 指定 JVM 参数
java -Xms512m -Xmx1024m -jar smart-recruitment-platform-1.0.0.jar
```

### 5.3 Windows 服务部署（可选）

使用 WinSW 将应用注册为 Windows 服务：

1. 下载 WinSW：https://github.com/winsw/winsw/releases
2. 创建配置文件 `smart-recruitment.xml`：

```xml
<service>
  <id>smart-recruitment</id>
  <name>Smart Recruitment Platform</name>
  <description>智能招聘匹配平台</description>
  <executable>java</executable>
  <arguments>-jar smart-recruitment-platform-1.0.0.jar</arguments>
  <logpath>logs</logpath>
  <log mode="roll-by-size">
    <sizeThreshold>10240</sizeThreshold>
    <keepFiles>5</keepFiles>
  </log>
</service>
```

3. 安装并启动服务：
```bash
smart-recruitment.exe install
smart-recruitment.exe start
```

### 5.4 Linux Systemd 服务部署

创建服务文件 `/etc/systemd/system/smart-recruitment.service`：

```ini
[Unit]
Description=Smart Recruitment Platform
After=syslog.target network.target mysql.service redis.service

[Service]
User=www-data
WorkingDirectory=/opt/smart-recruitment
ExecStart=/usr/bin/java -jar /opt/smart-recruitment/smart-recruitment-platform-1.0.0.jar
SuccessExitStatus=143
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable smart-recruitment
sudo systemctl start smart-recruitment
sudo systemctl status smart-recruitment
```

### 5.5 Docker 部署（可选）

**Dockerfile:**
```dockerfile
FROM eclipse-temurin:17-jre-jammy
WORKDIR /app
COPY target/smart-recruitment-platform-1.0.0.jar app.jar
EXPOSE 8081
ENTRYPOINT ["java", "-jar", "app.jar"]
```

**构建并运行:**
```bash
docker build -t smart-recruitment:1.0.0 .
docker run -d \
  --name smart-recruitment \
  -p 8081:8081 \
  -e DB_URL=jdbc:mysql://host.docker.internal:3306/smart_recruitment \
  -e DB_USERNAME=root \
  -e DB_PASSWORD=123456 \
  smart-recruitment:1.0.0
```

## 6 前端部署

### 6.1 前端项目

前端项目位于 `LongCatVue` 目录，基于 Vue.js 构建。

### 6.2 构建前端

```bash
cd LongCatVue

# 安装依赖
npm install

# 开发模式运行
npm run dev

# 生产模式构建
npm run build
# 构建产物在 dist/ 目录
```

### 6.3 Nginx 配置（生产环境推荐）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /var/www/smart-recruitment/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://localhost:8081/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_read_timeout 120s;
        client_max_body_size 10m;
    }

    # 上传文件代理
    location /uploads/ {
        proxy_pass http://localhost:8081/uploads/;
    }
}
```

## 8 常见问题

### 8.1 启动失败

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 数据库连接失败 | MySQL未启动或配置错误 | 检查MySQL服务状态和连接配置 |
| Redis连接失败 | Redis未启动或配置错误 | 检查Redis服务状态和连接配置 |
| 端口被占用 | 8081端口已被占用 | 修改server.port或停止占用进程 |
| 表不存在 | schema.sql未执行 | 检查spring.sql.init.mode配置 |

### 8.2 运行异常

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| AI接口超时 | 网络不稳定或API限流 | 检查网络连接，调整timeout配置 |
| 文件上传失败 | 路径不存在或权限不足 | 检查upload.local-path路径和读写权限 |
| OOM内存溢出 | JVM堆内存不足 | 增大 -Xmx 参数 |

### 8.3 数据库初始化

如需重新初始化数据库：
```sql
-- 删除并重建数据库
DROP DATABASE smart_recruitment;
CREATE DATABASE smart_recruitment DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
重启应用后将自动执行 `schema.sql` 重建表结构。

```bash
grep "ERROR" app.log
```

```bash
# 备份数据库

# 恢复数据库
mysql -u root -p smart_recruitment < backup_20260609.sql
```

```bash
# 1. 备份数据库
mysqldump -u root -p smart_recruitment > backup.sql

sudo systemctl stop smart-recruitment

# 4. 启动新服务
sudo systemctl start smart-recruitment

# 5. 验证服务
curl http://localhost:8081/api/auth/stats
```

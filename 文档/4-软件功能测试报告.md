## 1 测试概述

### 1.1 测试目的

验证智能招聘匹配平台各功能模块的正确性、稳定性和可用性，确保系统满足需求规格说明书中定义的功能要求。

### 1.2 测试范围

本次测试覆盖系统全部14个功能模块，共计60+个API接口，包括：
- 用户管理模块
- 简历管理模块
- 职位管理模块
- 智能匹配模块
- 投递管理模块
- 面试管理模块
- 企业管理模块
- 收藏管理模块
- 通知管理模块
- 论坛模块
- 管理后台模块
- AI服务模块
- 技能图谱模块
- 操作日志模块

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11 Pro |
| JDK | OpenJDK 17 |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis |
| 后端端口 | 8081 |
| 上下文路径 | /api |
| AI服务 | LongCat 2.0 Preview |
| 测试工具 | JUnit 5 + Spring Boot Test + MockMvc |
